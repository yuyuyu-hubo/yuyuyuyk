# 团子的秘密花园 · 商品选款网站

一个根据你的菜单文档自动生成的商品选款网站。顾客可以浏览、搜索、按分类筛选并「点选」自己想要的款式；商家可以上传新商品、编辑、删除商品，数据会真正保存下来。

## 目录结构

```
选款网站/
├── 启动网站.bat          ← 双击这个文件启动网站（Windows）
├── server.js             ← 后端服务（纯 Node 内置模块，零依赖）
├── data/
│   ├── products.json     ← 商品与分类数据
│   ├── submissions.json  ← 顾客提交的选款记录
│   └── config.json       ← 微信推送等设置
└── public/               ← 网站前端
    ├── index.html        ← 顾客端页面
    ├── merchant.html     ← 商家管理页面
    ├── login.html        ← 商家端登录页
    ├── css/style.css
    ├── js/customer.js    ← 顾客端逻辑
    ├── js/merchant.js    ← 商家端逻辑
    ├── js/login.js       ← 登录逻辑
    ├── assets/products/  ← 从你文档里提取的 39 张商品图
    └── uploads/          ← 商家上传的新图片（自动保存到这里）
```

## 怎么运行

### 第一次使用

1. 双击 **`启动网站.bat`** 即可（脚本会自动寻找电脑上的 Node.js；若找不到会提示你安装）。
2. 用浏览器打开 **http://localhost:3000** 即可使用。

> 如果没有安装 Node.js：到 <https://nodejs.org/zh-cn> 下载并安装 **LTS 长期支持版**，然后重新双击 `启动网站.bat`。
> 也可以手动运行：在本目录打开命令行，执行 `node server.js`。

### 局域网分享（让手机 / 其他电脑一起用）

启动后，命令行会提示一个局域网地址。也可以在命令行输入 `ipconfig` 查看本机 IPv4 地址（形如 `192.168.x.x`），然后让其他设备访问：

```
http://192.168.x.x:3000
```

注意：手机和电脑需要连接同一个 WiFi；如被系统防火墙拦截，请允许 Node.js 通过专用网络。

### 停止网站

在启动窗口按 `Ctrl+C`，或直接关闭那个黑色命令行窗口即可。

## 功能说明

网站分两个独立页面：

- **顾客端** — 打开 `http://localhost:3000/`
  - 浏览全部商品，按分类筛选，按名称 / 货号搜索。
  - 点「＋ 选这款」加入「已选款式」；点商品图片可查看**多图详情**，左右翻页或点缩略图浏览。
  - 「已选款式」抽屉里可：**提交选款**（填称呼和联系方式，商家会在微信收到通知）、复制清单、清空。
  - 已选款式保存在当前浏览器本地。
- **商家端** — 打开 `http://localhost:3000/merchant.html`（顾客端右上角「♥ 姐姐入口」）
  - 首次访问需输入**访问密码**（默认 `123456`）。
  - 上传新商品：**一次可上传多张图片**，可填名称、分类、货号、价格、备注。
  - **分类管理**：自由新增、删除分类（删除后其下商品自动归入「未分类」）。
  - 商品编辑 / 删除；删除商品时其上传图片一并清理。
  - **收到的选款**：查看顾客提交的选款清单。
  - **微信推送设置**：填入 Server酱 SendKey，顾客提交选款时自动推送到你的微信。
  - 数据真正保存到服务器（`data/products.json`、`data/submissions.json`、`data/config.json` 与 `public/uploads/`）。

## 微信推送（Server酱）怎么开通

1. 用微信扫码登录 <https://sct.ftqq.com>（Server酱）。
2. 按提示关注它的公众号，获取一个 **SendKey**（形如 `SCTxxxxxxx`）。
3. 回到本站商家端 → 底部「微信推送设置」，粘贴 SendKey 并点「保存」。
4. 之后顾客「提交选款」，你的微信就会收到一条通知，内容包含顾客称呼、联系方式、备注和完整选款清单。

> 免费版 Server酱 每天有发送条数限制；推送需要商家端所在电脑能联网。未配置 SendKey 时，选款仍会正常保存在「收到的选款」里，只是不推微信。

## 商家端访问密码

- 默认密码是 **`123456`**。
- **修改密码**：用记事本打开 `server.js`，找到这一行：

  ```js
  const ADMIN_PASSWORD = process.env.ADMIN_PASSWORD || '123456';
  ```

  把 `123456` 改成你自己的密码，保存后重启 `启动网站.bat` 即可生效。
- 也可以在启动前设置环境变量 `ADMIN_PASSWORD`（优先级更高）。
- 密码校验在服务端完成，商家端的商品新增/编辑/删除接口都受保护；顾客端浏览、点选款式不受影响。

## 常见问题

- **改了端口**：修改 `server.js` 里的 `PORT` 常量，或在启动前设置环境变量，例如 `set PORT=8080`。
- **想重置商品数据**：删除 `data/products.json` 后重启即可恢复初始的 39 件商品（但需保留 `public/assets/products/` 里的图片）。
- **上传图片大小限制**：单张图片建议不超过 20MB（前端限制），服务器端整体请求限制 25MB。
